# 2026-10-26 decision: server JS gzip ceiling 335104 -> 335360

`server.js.maxGzipBytes` rises 335104 -> 335360 in
`ci/budgets/kit/server-js.json`; no other ceiling changes. This admits the
event-egress stored-text bound (PR #1849), whose server-side value code
grows the Kit server bundle past the current ceiling. One 256B step, the
smallest aligned cover for the measured worst case.

## Measurements

Locked Node 24.22.1 / npm 11.19.1 production builds
(`npm run build --prefix web`), measured through
`node ci/check-kit-perf.mjs`, two builds per tree. Worst case governs.

Pristine main tip `f6b97d9f` (decision-doc-only #1789 included):

| Build | Server files | Raw bytes | Gzip bytes | Gate |
|---|---:|---:|---:|---|
| 1 | 116 | 1182429 | 334842 | exit 0, margin 262 |
| 2 | 116 | 1182431 | 334843 | exit 0, margin 261 |

Combined tree `8361bb09` (feature plus main #1780; build-input-identical
to main tip plus the feature, because #1789 adds only this directory's
decision doc and no `web/`, `src/`, manifest or lockfile byte):

| Build | Server files | Raw bytes | Gzip bytes | Gate |
|---|---:|---:|---:|---|
| 1 | 116 | 1184924 | 335321 | exit 1, 217 over |
| 2 | 116 | 1184924 | 335322 | exit 1, 218 over |

CI on the same combined head measured gzip 335323 (run 40408120997),
1B above the local worst and inside rebuild jitter. Worst case overall
is therefore 335323: the current 335104 ceiling rejects it by 219B,
and 335360 (256 x 1310) admits it with 37B of margin. Worker
(2551/1219B), client JS (54 files, 254929/102692B) and client CSS
(2 files, 2861/1019B) are byte-identical across all four builds and fit
their unchanged ceilings, so the growth is server-only with no new
files. Feature delta on the server total is +2493 raw / +479 gzip
bytes (local worst minus pristine worst).

Rebuild jitter is disclosed, not signal: pristine raw/gzip wobble by
+2/+1B across rebuilds, combined gzip by +1B, and CI sits +1B above
local worst. The checker itself is deterministic: repeated runs over
one build print identical bytes.

## Attribution

The only main-side commits since the last green Kit measurement
(#1475) are #1780 (CI/e2e/test files only) and #1789 (one decision
doc), touching no build input, so the growth belongs to the feature
diff. Its `src/events/reads.ts` value code (egress byte-budget
constants, the `admittedText`/`storedTextOver` SQL guards and the
`FeedEvent` projection) ships into the Kit server bundle through
`web/src/routes/events/past/+page.server.ts` (`listPast`); the
`src/events/feeds.ts` narrowings are type-only and the client total
confirms they add no client bytes.
