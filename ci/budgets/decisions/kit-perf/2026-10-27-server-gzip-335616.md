# 2026-10-27 decision: server JS gzip ceiling 335360 -> 335616

`server.js.maxGzipBytes` rises 335360 -> 335616 in
`ci/budgets/kit/server-js.json`; no other ceiling changes. This admits the
honest UTC clock-labels slice (PR #1906), whose shared `effectiveZone`
authority ships into the Kit server bundle past the current ceiling. One
256B step, the smallest aligned cover for the measured worst case.

## Measurements

Locked Node 24.22.1 / npm 11.19.1 production builds
(`npm run build --prefix web`), measured through
`node ci/check-kit-perf.mjs`, at least two builds per tree. Worst case
governs.

Pristine main tip `4cd035fd8`:

| Build | Server files | Raw bytes | Gzip bytes | Gate |
|---|---:|---:|---:|---|
| 1 | 116 | 1185439 | 335349 | exit 0, margin 11 |
| 2 | 116 | 1185441 | 335349 | exit 0, margin 11 |

Combined tree `a5886f87` (main tip plus PR #1906 head `31442bb0`,
merged cleanly, no conflict):

| Build | Server files | Raw bytes | Gzip bytes | Gate |
|---|---:|---:|---:|---|
| 1 | 116 | (not retained) | 335420 | exit 1, 60 over |
| 2 | 116 | 1185636 | 335418 | exit 1, 58 over |
| 3 | 116 | 1185638 | 335417 | exit 1, 57 over |

CI on the same feature head measured gzip 335405 (run 40446525706),
15B below the local worst; toolchain/merge skew, and the worst
governs either way. Worst case overall is therefore 335420: the
current 335360 ceiling rejects it by 60B, and 335616 (256 x 1311)
admits it with 196B of margin. The lower step 335104 rejects the
worst by 316B.

Rebuild jitter is disclosed, not signal: pristine raw wobbles by
+2B across rebuilds with gzip stable, combined gzip spans 3B
(335417-335420), inside the known +-3B rebuild jitter. The checker
itself is deterministic: six runs over one build print identical
bytes. Boundary controls on an archived combined build: 335104,
335360 and exact-minus-one 335417 reject; exact 335418 and proposed
335616 admit.

Worker (2551/1219B) and client CSS (2 files, 2861/1019B) are
byte-identical across all five builds. Client JS grows +29 raw/+6
gzip bytes (254926/102621B pristine, 254955/102627B combined) and
fits its unchanged ceilings, so the breach is server-only. No new
files: both trees emit the same 116 names.

## Attribution

Pristine tip fits the current ceiling by only 11B. A single isolated
build of the feature on its base measured 335406, so roughly +12B of
the combined total comes from main-side #1850 (Kit admin-bearer
rotation in `src/kit-session.ts`, which ships into the server
bundle); the remaining growth belongs to the feature diff: +197 raw
/ +71 gzip bytes worst case (local worst minus pristine worst).

The raw delta sits in exactly three chunks, every other counted chunk
size-identical: `chunks/events.js` +107B, `chunks/site-shell.js` +78B,
`chunks/src.js` +12B. The `effectiveZone` symbol occurs 0 times in
the pristine output and 7 times in the combined output (3/2/2 across
exactly those three chunks): the shared zone authority in
`src/events/date-format.ts` plus its archive-card call site in
`web/src/lib/EventCard.svelte`.
