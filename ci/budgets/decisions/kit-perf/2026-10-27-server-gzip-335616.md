# 2026-10-27 decision: server JS gzip ceiling 335360 -> 335616

`server.js.maxGzipBytes` rises 335360 -> 335616 in
`ci/budgets/kit/server-js.json`; no other ceiling changes. This admits the
moderator unrenderable-time inventory repair, whose server-side guards grow
the Kit server bundle past the current ceiling. One 256B step, the smallest
aligned cover for the measured worst case.

## Measurements

Locked Node 24.22.1 / npm 11.19.1 production builds
(`npm run build --prefix web`), measured through
`node ci/check-kit-perf.mjs`, two builds per tree. Worst case governs.

Pristine bot-merge base `ba58281d2` (main side of the PR merge, whose
exact-head `ci-ok` is green):

| Build | Server files | Raw bytes | Gzip bytes | Gate |
|---|---:|---:|---:|---|
| 1 | 116 | 1185441 | 335350 | exit 0, margin 10 |

Combined tree (base plus the three unrenderable-time commits, with the
`kit-event-edit` import golf that keeps the growth minimal):

| Build | Server files | Raw bytes | Gzip bytes | Gate |
|---|---:|---:|---:|---|
| 1 | 116 | 1187018 | 335608 | exit 1, 248 over |
| 2 | 116 | 1187018 | 335608 | exit 1, 248 over |

CI on the same combined content measured gzip 335585 (run 40459837305),
23B under the local worst and inside cross-environment build variance;
both reject the current 335360 ceiling. Worst case overall is therefore
335608: the current ceiling rejects it by 248B, and 335616 (256 x 1311)
admits it with 8B of margin. Worker (2551/1219B), client JS (54 files,
255345/102724B, margin 444) and client CSS (2 files, 2861/1019B) fit
their unchanged ceilings, so the growth is server-only with no new
files. Feature delta on the server total is +1577 raw / +258 gzip
bytes (local worst minus pristine).

Rebuild jitter is disclosed, not signal: the two combined builds agree
byte-for-byte, and the checker is deterministic over one build. The
8B margin is thin by construction -- it is the smallest 256B-aligned
cover -- and any future growth fails closed onto the next step.

## Attribution

The combined tree is the pristine base plus exactly the three
unrenderable-time commits; no other main-side change rides along (the
bot merge's main side IS the measured pristine base). The growth
belongs to the feature diff: `renderableIso` plus the finite-instant
guards in `src/admin/kit-events.ts`, `src/admin/kit-event-edit.ts`
(without which one bad row throws the whole inventory),
`src/admin/pages/events-list.tsx`, `src/admin/pages/shell.tsx`,
`src/admin/store-event-writes.ts`, and the Kit list placeholder in
`web/src/routes/admin/events/+page.svelte`, all of which ship into the
Kit server bundle through the Hono catch-all and the Kit admin nodes.
Test, decision-doc, workflow and fixture files touch no build input.
