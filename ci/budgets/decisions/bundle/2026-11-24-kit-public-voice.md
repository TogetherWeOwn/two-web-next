# Kit public voice count bundle

The Kit homepage loads this island only when the existing live socket flag is
enabled and the session state is known. It bundles the existing browser
transport and updates the public count beside the home stats.

Measured 3,398 raw and 1,634 gzip bytes. The ceiling is 4,608 raw and 2,048
gzip bytes, the measured size multiplied by 1.25 and rounded up to 512-byte
and 256-byte boundaries respectively.
