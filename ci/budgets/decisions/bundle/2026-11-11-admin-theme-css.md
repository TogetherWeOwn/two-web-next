# Kit admin register sheet

The new `public/admin-theme.css` is the Kit-only admin register: it aligns the
shared AdminShell chrome (dashboard, events, featured content, join attempts,
activity log) with the pinned kit tokens in the denser admin register, scoped
under `.kit-admin` so Hono keeps its frozen light palette. It is a new served
asset, generated by minifying `assets/admin-theme.css` via
`npm run build:assets`; the drift check fails CI on any difference.
