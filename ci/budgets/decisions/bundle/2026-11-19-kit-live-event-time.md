# Kit live detail timezone bundle

The Kit live page replaces the existing timezone script with its C4-aware
variant, not an additional island. The variant retains timezone conversion
and uses the shared clock to withdraw dated claims. Hono and non-live Kit
pages retain their original assets.

Measured 3733 raw / 1652 gzip bytes. The new ceiling is 5120 / 2304 bytes
(measured ×1.25, rounded up to 512 / 256 bytes). No existing ceiling changes.
