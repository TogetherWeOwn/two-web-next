1. Mona Sans variable (font.display: display and all UI)
   Upstream: Google Fonts css2 family=Mona+Sans:wght@200..900 (monasans v4),
   axis wght 200-900 (no wdth axis), latin subset.
   File: mona-sans-latin-wght.woff2 (39788 B)
   sha256: a59061e38c5e7e6a00aaa6b6645a220c7d9c530991167f058cc0f8575f5d5844
   Source bytes are Google's exact latin subset, unmodified. Of the arrows
   it covers only U+2191/U+2193 (up/down); left/right arrows keep system
   rendering.
   Glyph outlines and advances match the previous wght+wdth file at width 100.
   Retiring: mona-sans-latin-var.woff2 (98124 B, sha256
   5ea3740633e5ac7af56c13d7e8ec32bcae12e7723e53d34284469a8947ccb2f3; the same
   family with the unused wdth 75-125 axis) is no longer referenced and is
   removed in a follow-up change once cached pages have expired.
   Copyright: 2022 The Mona Sans Project Authors
   (https://github.com/github/mona-sans), Reserved Font Name "Mona".
   Served with font-display: swap, preloaded once on themed pages.
   Metric-matched fallback 'Mona Sans Fallback' (local Liberation Sans /
   Arimo / Arial): size-adjust 103.33%, ascent-override 105.49%,
   descent-override 30.97%, line-gap-override 0%, unicode-range U+0000-00FF.
   Derived by matching average advance widths over printable ASCII at
   wght 400 / wdth 100 against Arimo (Arial-metric-compatible), then
   scaling hhea ascent/descent by the same factor. See bin/fetch-ember-fonts.sh.
