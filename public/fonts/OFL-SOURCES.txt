Living Lobby type system (design §3.2). Subset woff2 files built from the
upstream OFL releases with bin/fetch-lobby-fonts.sh (sha256-verified
inputs, instanced where variable, Google-Fonts-"latin" unicode set).
Re-run that script and diff this directory to audit any file.

(see LICENSE.txt in this directory for the full text).

1. Space Grotesk 500 / 700 — display + band headings
   Upstream: https://github.com/floriankarsten/space-grotesk
   Source file: SpaceGrotesk[wght].ttf (variable, wght 300-700), instanced
   Version 2.000. Copyright 2020 The Space Grotesk Project Authors.
   Files: space-grotesk-latin-500.woff2, space-grotesk-latin-700.woff2

2. Atkinson Hyperlegible 400 / 700 — body + UI
   Upstream: https://github.com/google/fonts (ofl/atkinsonhyperlegible)
   Source files: AtkinsonHyperlegible-Regular.ttf,
   AtkinsonHyperlegible-Bold.ttf (static).
   Version 1.006. Copyright 2020 Braille Institute of America, Inc.
   Files: atkinson-hyperlegible-latin-400.woff2,
   atkinson-hyperlegible-latin-700.woff2

3. IBM Plex Mono 400 / 500 — data (counts, dates, freshness, zones)
   Upstream: https://github.com/IBM/plex
   (via https://github.com/google/fonts, ofl/ibmplexmono)
   Source files: IBMPlexMono-Regular.ttf, IBMPlexMono-Medium.ttf (static).
   Version 2.3. Copyright 2017 IBM Corp. All rights reserved.
   Files: ibm-plex-mono-latin-400.woff2, ibm-plex-mono-latin-500.woff2

4. Source Serif 4 italic 600 — records names only
   Upstream: https://github.com/adobe-fonts/source-serif
   (via https://github.com/google/fonts, ofl/sourceserif4)
   Source file: SourceSerif4-Italic[opsz,wght].ttf (variable),
   instanced to wght 600 / opsz 24.
   Version 4.004. Copyright 2014-2021 Adobe Systems Incorporated,
   with Reserved Font Name "Source".
   File: source-serif-4-latin-600-italic.woff2
