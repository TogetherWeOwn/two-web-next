# Decision 0005: the post-cutover milestone proposal is superseded and kept only as history

- Status: accepted (recorded 2026-11-09)
- Deciders: the Engineering Lead (record); the Product Lead (direction placement)
- Historical proposal: [post-cutover milestone](../post-cutover-milestone.md)

## Context

A post-cutover milestone proposal in the repository described possible next
steps after the Worker cutover. Later direction work produced the public
website roadmap, which is now the single entry point for direction.

## Decision

The public `ROADMAP.md` is the direction entry point, and the
post-cutover milestone proposal is retained in the repository as history
only. Its remaining ideas are not newly approved scope and do not become
commitments; each needs acceptance through normal product planning before
implementation.

## Why

One entry point avoids two documents competing for the same authority. The
proposal still has value as a record of what was considered, so it stays —
labelled as history, where readers can find it without mistaking it for a
plan.

## Provenance

Direction recorded in the public roadmap entry (2026-11-09): the roadmap
entry pull request preserved the post-cutover proposal and marked it
historical.
